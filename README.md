# WAFADAR TOBACCO — HTML, CSS & JavaScript

ZIP extract karein, phir index.html browser mein open karein. Koi installation ya build zaroori nahi.

- index.html — complete one-page website
- styles.css — colours, styling aur mobile layout
- script.js — mobile menu aur product details
- assets/ — product image aur favicon

Files aur assets folder saath rakhein. Google font ke liye internet chahiye; offline sans-serif fallback chalega. Wafadar Tobacco naam aur products sample concepts hain. Website orders ya payments accept nahi karti.
